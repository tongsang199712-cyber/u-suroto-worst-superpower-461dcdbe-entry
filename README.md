# Worst Superpower

A one-line entry for make.fun's Worst Superpower bounty: the most useless superpower imaginable.

Teleportation sounds like the ultimate fantasy — until the small print
lands. This power only takes you to places you have just left, so every
heroic escape ends exactly where you started, one room behind yourself.
Zero distance gained, every single time.

## The line

> I can teleport anywhere, but only to places I have just left.

## How it works

`main.ts` writes the entry line to `/output/entry.txt` — exactly one line,
no trailing newline, 61 characters (within the 1–140 character gate). It
then reads the file back and verifies it is byte-identical to the line.

Run it with:

```sh
node main.ts
```
